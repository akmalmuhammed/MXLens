# Code of Conduct

## Our pledge

We want MXLens to be a welcoming, harassment-free project for everyone,
regardless of background or identity.

## Expected behavior

- Be respectful and assume good faith.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and its users.

## Unacceptable behavior

- Harassment, insults, or discriminatory jokes and language.
- Personal or political attacks.
- Publishing others' private information without permission.
- Using the project to develop or distribute material intended to harm others.

## Scope

This applies in all project spaces — issues, pull requests, discussions — and in
public spaces when representing the project.

## Enforcement

Report unacceptable behavior to the maintainer via a private GitHub security
advisory or direct message. Reports are handled confidentially. Maintainers may
remove content, or block contributors, that violates this code.

This Code of Conduct is adapted from the Contributor Covenant, version 2.1.
